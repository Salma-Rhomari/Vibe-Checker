# Vibe Checker 

A simple web app that suggests a music genre and artist based on your current mood.

## Features
- 4 mood options: Chill, Energetic, Focus, Melancholic
- Dynamic background color that changes with your mood
- Genre & artist recommendations (deep house, afro house, melodic house)

## Tech stack
- HTML
- CSS
- JavaScript
